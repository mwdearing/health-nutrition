# Shared custom products — 0.1.17

Source integration is implemented. Hosted deployment, final Apple validation and client release remain pending; these notes do not announce availability.

- Save standalone food, drink and supplement definitions with optional barcodes, explicit serving information and structured facts. Existing logged snapshots keep their original facts.
- Eligible new products enqueue atomically on Save and, after that transaction succeeds, start delivery immediately when the foreground coordinator is ready. Imports, edits and selected historical repairs stay local until deliberate review; no later backfill.
- Share a selected product after reviewing product-only details and the current disclosure. Durable operations distinguish local save, pending delivery, acknowledgment, removal and failures; recovery handles offline work and lost replies without silently publishing canceled work.
- Search foods by name, inspect representative and paged alternative facts, then deliberately save the representative without uploading intake or creating agreement. Verification requires exact owner review. Library verification evidence describes the imported revision at import and is discarded when its facts are edited.
- Review conflicts and newer same-account state explicitly. Older acknowledgments and pending descendants cannot silently overwrite newer server contributions.
- Integrate scoped session lifecycle safeguards, exact-token invalidation, bounded Community response loading and source-aware legacy labels. Ordinary permission/consent failures retain credentials; logout and account changes close delivery admission before awaiting network work.

The migration order is owner verification, shared-products base, legacy bridge, publish resolution, then bounded publication/alternatives. The first four migration files remain byte-for-byte unchanged. Local synthetic checks cover fresh/seeded/upgrade/concurrency and large alternative sets, recovery wrappers and legacy display projection. Real Apple SwiftPM, Debug simulator tests, Release build and inspected screenshots remain required. A shared decimal-keyboard modifier access correction passed a disposable same-module, cross-file Swift compile probe plus local syntax/lint; Apple compilation remains pending. Backend capability verification precedes client release, and the protected release approval remains with the owner.
