# Security Policy

Health Nutrition is a planned native iOS food, supplement, and hydration app with a community catalog and HealthRelay integration. No application release is currently available.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/mwdearing/health-nutrition/security/advisories/new). Do not post sensitive findings in public issues or pull requests.

Use synthetic data and provide the affected component, impact, and reproduction steps. Do not include personal health data, credentials, tokens, private keys, signing material, or private deployment details.

## Repository safeguards

Secret scanning and push protection, Dependabot alerts and security updates, and private vulnerability reporting are enabled. The default branch requires pull requests and prohibits force pushes and deletion, without bypass actors.

Application-specific security guidance, supported versions, CodeQL scanning, and build requirements will be established with the project scaffold.
